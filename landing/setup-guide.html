Setup guide

Three ways to run Mini Numbers. Pick one; they all end at the same setup wizard.

On a server (recommended)

You need a small Linux server with Docker, and a domain name pointing at it. HTTPS sorts itself out.

Terminal 
# In an empty folder on your server
curl -fsSLO \
  https://raw.githubusercontent.com/OneManStudioDotSe/mini-numbers/main/docker-compose.yml
echo "DOMAIN=stats.example.com" > .env
docker compose up -d

Then open https://stats.example.com. If nothing loads, check that ports 80 and 443 are open in your provider's firewall.

On your own computer

For a look around before you commit to anything.

Terminal 
docker run --rm -p 8080:8080 -v mini-numbers-data:/app/data ghcr.io/onemanstudiodotse/mini-numbers:latest

Then open http://localhost:8080.

Without Docker

With Java 21 installed, download mini-numbers.jar from the latest release and run it.

Terminal 
java -jar mini-numbers.jar

The setup wizard

The first time you open Mini Numbers, it asks six things:

  1. Login: a user name and password.
  2. Storage: SQLite (one file, right for most sites) or PostgreSQL.
  3. Privacy mode: Standard, Strict or Paranoid.
  4. Server settings: the defaults are fine.
  5. Limits: the defaults are fine here too.
  6. Review: paste the setup token and launch.

The setup token proves the server is yours, so a stranger can't finish the setup before you do. Find it in the server's log:

Terminal 
docker compose logs mini-numbers | grep "Setup token"

Don't feel like answering questions? Quick Setup fills everything in and shows you a generated password once. Copy it.

Add your site

Sign in, click New project, and paste the snippet it gives you into your site:

your-site.html 
<script async
  src="https://stats.example.com/tracker/tracker.min.js"
  data-project-key="YOUR_PROJECT_KEY"></script>

That's it. Open your site in another tab and watch yourself appear.

Settings you might want later

The wizard saves everything in a .env file. These are the ones people actually change:

SettingDefaultWhat it does
PRIVACY_MODESTANDARDHow much is stored: STANDARD, STRICT or PARANOID
HASH_ROTATION_HOURS24How long before a visitor is forgotten (1 to 8,760)
DATA_RETENTION_DAYS0Delete events older than this many days (0 keeps them)
DB_TYPESQLITESQLITE or POSTGRESQL
TZServer'sThe time zone your days and hours are counted in
LABSEmptySwitches on the experimental features, such as revenue or webhooks

The full list lives in the configuration page.

When something's off

Nothing shows up in the dashboard

  • Is the key in your snippet the one from the project's Settings?
  • Does your browser send Do Not Track or Global Privacy Control? Then you're not counted, on purpose.
  • Open the browser's network tab and look for a request to /collect.

I can't sign in

Signing in needs HTTPS (or localhost). Opening the server by its IP address over plain HTTP won't work.

I forgot my password

Terminal 
docker compose exec mini-numbers java -jar /app/app.jar reset-password admin

It won't start

The log usually says why: docker compose logs mini-numbers.
